# NuzLike alpha 5

Alpha 5 fixes an issue in Pokémon Crystal where exhausted wild encounters could
still trigger the visible start of a battle before being cancelled. NuzLike now
rejects those encounters before Crystal queues the battle transition, while the
single intended “But no one came…” encounter still works normally.

Existing runs do not need to restart.

NuzLike is still alpha software and has not been played through end to end in
every game. Keep your original game backup untouched and use a separate save you
are prepared to lose.
