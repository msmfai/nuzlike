# NuzLike alpha 5

## What changed

Pokémon Crystal no longer flashes as though a wild battle is starting after you
have already used the encounter for that area. Once an area's encounter is
exhausted, you can continue through the grass without repeated false battle
starts.

The area's one-time “But no one came…” encounter still appears as intended.

Existing runs do not need to restart.

## Crystal fixes included in this build

If you are updating from an older alpha, this build also includes these Crystal
fixes:

- Areas such as Dark Cave no longer freeze when every available wild species
  has already been caught.
- A Pokémon's first Trainer experience award no longer briefly gives it an
  invalid level.
- Experience shared by the level cap can now trigger normal move learning and
  evolution.
- Level caps remain enforced after the battle dialogue closes.
- NuzLike's experience messages stay within the battle text box.

These five fixes were already present in Alpha 4. If you are updating from
Alpha 4, the exhausted-encounter battle flash is the new player-facing fix in
Alpha 5.

## Alpha warning

NuzLike is alpha software and not every game has been played through from start
to finish. Keep your original game backup untouched and use a separate save you
are prepared to lose. Bug reports are very welcome.
